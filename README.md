# 🎓 CampusGuide AI — Smart College Assistant

### AI-Powered College Information Assistant Using Retrieval-Augmented Generation (RAG)

CampusGuide AI is an AI-powered smart college assistant designed to help students quickly find information from college documents. It allows students to upload PDF documents, ask questions, receive relevant answers, and practice their knowledge through interactive quizzes.

Our goal is to make college information easier to access and learning more interactive.

---

## 🚀 Features

* 💬 **AI Chatbot:** Ask questions about college information.
* 📚 **Multiple PDF Uploads:** Upload college documents for analysis.
* 🔍 **Semantic Search:** Retrieve relevant information from uploaded documents.
* 📄 **Source-Based Answers:** View supporting information from documents.
* 📝 **AI-Generated Quizzes:** Generate multiple-choice questions from document content.
* ✅ **Automatic Quiz Evaluation:** Check answers and calculate scores.
* 🌐 **Interactive Interface:** Easy-to-use web interface built with Gradio.

---

## 🛠️ Technologies Used

* **Python** — Core programming language
* **Google Colab** — Development environment
* **Gradio** — User interface
* **Sentence Transformers** — Text embeddings for semantic search
* **Retrieval-Augmented Generation (RAG)** — Retrieves document information to support answers
* **Gemma** — AI language model, if configured in the project

---

## ⚙️ How It Works

1. Upload college PDF documents.
2. Extract text from the documents.
3. Split the text into smaller sections.
4. Convert the text sections into embeddings.
5. Retrieve relevant sections when a student asks a question.
6. Generate an answer based on the retrieved information.
7. Generate quizzes to help students test their understanding.

---

## 💻 How to Run the Project

1. Open `CampusGuide_AI.ipynb` in Google Colab.
2. Run the setup and installation cells.
3. Run the notebook cells in order to initialize the required models and functions.
4. Run the final Gradio interface cell.
5. Open the generated web interface.
6. Upload college PDFs and start asking questions or generating quizzes.

**Note:** The project requires the dependencies and AI model configuration specified in the notebook. Some models may require an internet connection or additional setup.
